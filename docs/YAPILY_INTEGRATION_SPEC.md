# Yapily Integration Specification

This project contains only the provider boundary. Insert the separately reviewed
Yapily implementation after confirming:

- Reserved's approved AIS and VRP products;
- supported UK institutions and institution-specific constraints;
- unique application-user identifiers;
- signed callback state;
- encrypted consent-token storage;
- consent expiry and reauthorisation;
- transaction pagination and persistent transaction identifiers;
- cautious invoice matching;
- sandbox evidence for each supported bank.
