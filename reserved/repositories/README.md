# Repositories

Repository classes will isolate database access from routes and engines.

For the October launch, the Replit preview uses demo data. Before a live beta,
add repositories for:

- authenticated users;
- tax profiles;
- calculations and immutable calculation versions;
- bank consents and transactions;
- accounting connections and invoices;
- capital disposals and CGT summaries;
- payment requests, transfers and append-only sweep events.
